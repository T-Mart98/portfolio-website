Here are a few projects that I have made on my journey as a future Front-end Engineer.

They all have given me a solid foundation and I have learned so much by creating them.

Responsive Club Website

The goal for this project was to make a website for a fake club. I chose a basketball club and used a unique graffiti esque font face and monochromatic color scheme to really embody pure basketball culture. The website needed to be responsive for multiple device screens. I achieved this using a combination of semantic HTML, CSS Flexbox and media queries.

Company Homepage

The goal for this project was to make a homepage for a fake company. I chose a spider pet shop. The website needed to be responsive. The product cards needed to change orientation based on different screen sizes. I achieved this using a combination of semantic HTML, CSS Flexbox and media queries.

Responsive Club Website

This project is one of the earliest I have made and a personal favorite. I was able to get a taste for what goes behind making a great website, a style guide. I tried to be as creative as I could with the color scheme and the use of gradients. I created this website using semantic HTML and knowledge learned from the CSS box model.
