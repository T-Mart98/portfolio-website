## My process

I stared this project by choosing to create a portfolio website and then taking inspiration from others. After that I had to get specific with my project which lead me to defining my target audience, researching the competition, defining my goals and success metrics and finally creating a content inventory and creative brief with all I had accumulated. The next steps in my process was to think about and define the information architecture and UX of my site by creating a site map, a user persona, a journey map and a low-fidelity wireframe for my project. A high-fidelity mockup for both desktop and mobile was next, after settling on a desgin system that was compliant with WCAG accessibility standards for contrast, colors, and sizing and spacing for font and buttons. The last step was to start writing code following the creation of a list of comprehensive root pseudo classes that included everything from my design system.
